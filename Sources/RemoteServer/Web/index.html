Display and scaling

Use 100% for available pixel detail, or zoom in to inspect a small area. Hold Alt/Option and scroll, or drag the scrollbars, to pan. Regular scrolling controls the remote computer. Zooming cannot restore detail lost in transmission.

On touch screens, enable Pan view and drag to inspect details.

Use virtual display only

Reading display status…

Create and select a virtual display in Display, confirm the video works, then turn off the Mac's built-in and external physical displays. The current user session stays active.

Local keyboard, mouse, or trackpad input restores physical displays. Remote input continues on the virtual display. Disconnects, exits, and failures automatically attempt to restore the original display layout.

This does not lock the Mac. When macOS actually locks, remote control shows the system lock screen for password entry.

Mouse and touch

Slide one finger to move the pointer, tap to click, long-press to right-click, and scroll with two fingers. Enable Drag to drag items.

Swipe left with four fingers for the next desktop, right for the previous desktop, or up for Mission Control.

Requires the Mac's Control + arrow key shortcuts. Use these buttons if your touch device intercepts the gestures.

Remote keyboard Keys are sent to the Mac

Input is masked and cleared after sending or closing the keyboard. Select the macOS password field in the video first, send, then press Enter on the remote keyboard.

Tap ⌘ / ⌥ / ⌃ / ⇧ to combine modifiers. Copy and paste use the host Mac's clipboard.
