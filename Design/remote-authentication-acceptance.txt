交付
- 设置 → 远程控制 → 认证方式：自定义密码 / macOS 系统账户。
- 自定义模式保留 PBKDF2 密码及旧配置兼容；只有缺失 authenticationMode 的旧配置迁移为自定义。
  未知/空模式、缺失系统账户、无效身份、损坏配置均失败关闭，不静默降级。
- 系统模式使用 Apple OpenDirectory 的 ODRecord.verifyPassword；不读取系统密码数据库。
  仅解析本机目录节点、当前非 root 且 real/effective UID 相同的后台所属账户。
  绑定 UID + GeneratedUID(UUID) + 短账户名；用户不能从客户端指定任意账户。
  配置保存公开账户标识，不保存系统密码；不把密码放在 URL、日志或返回值中。
- 启动、周期性运行及认证前后检查账户认证策略，身份变化/策略拒绝时撤销会话并关闭监听。
  系统模式单次并行认证，所有源 IP 共享账户失败限流，系统锁定/过期策略仍生效。
- 切换方式会断开连接、释放输入并撤销会话；异步认证期间改配置或停止再恢复服务不能签发旧请求 token。
- 选择认证方式不自动开启远控；切回未配置密码的自定义模式时关闭远控。
- 网页显示实际认证方式及绑定账户；原生控制端有认证说明，两端登录绑定方式/配置版本。
  密码输入在提交/失败后清空；系统模式网页关闭密码自动完成；密码不写入应用持久存储。
- 密码只在当次认证请求的内存中处理，Swift/Foundation 不提供此实现中所有临时副本的可靠清零保证。

实现依据
- 本机 SDK OpenDirectory/ODRecord.h：verifyPassword 会执行账户及密码认证策略。
- https://developer.apple.com/documentation/opendirectory/odrecord/verifypassword(_:)
- https://developer.apple.com/documentation/opendirectory/odrecord/authenticationallowed()
