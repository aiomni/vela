AwakePet 虚拟显示器与隐私远控验收记录
日期：2026-11-02 至 2026-11-03；环境：本机 arm64 / macOS 27.0.1。
状态：实现、分项验证与签名构建完成；现场最终验收尚未完成。目标保持 active。

已实现
- 网页虚拟显示器创建/替换/关闭、像素宽高、HiDPI、实际显示/采集/接收尺寸。
- 动态系统能力检查；私有接口缺失时明确拒绝；虚拟屏不改变主屏，只在现有布局右侧添加。
- 本机系统登录界面保护，原用户后台会话继续；会话切换后匹配显示器身份并重建采集。
- 输入送往当前用户会话，不送往物理控制台登录界面。会话状态变更或显示器失效时停止输入。
- 普通锁屏保留连接，暂停输入/采集，网页完全遮挡旧画面。恢复后台操作需当前 Mac 账户验证。
- Mac 验证与入口认证独立，共享系统账户失败预算；不存密码，连接和配置变化后丢弃旧验证结果。
- 完全断开清除后台会话授权，下一次控制者必须重新验证；同一控制者短时重连保留当前虚拟屏。
- 断线/退出释放输入、虚拟屏和电源断言，本地登录保护继续。无持久显示器禁用配置需恢复。
- 本机唤醒并正常登录可恢复物理桌面；网页结束隐私会话不会自动登录本机。

明确限制/待验收
1. 用户“没注意到，稍后再验证”：未确认实体内屏是否黑屏，未连接外接显示器，不保证所有设备无信号。
2. 最终网页中真实 Mac 账户密码验证 → 后台恢复 → 点击聚焦再输入，需要用户现场验证。
   原型已分别证明后台采集/输入与锁屏后采集，但不能冒充最终整条流程通过。
3. 私有接口可能随系统升级改变。后台不能可靠创建/修改虚拟屏，所以必须先配置再进入隐私会话。
4. 不支持 FileVault、首次登录前、所有合盖场景。已有其他电源断言可能影响物理屏休眠表现。
5. 断线和崩溃后本地仍受系统登录保护，虚拟显示器随对象/进程释放；未以强杀当前生产应用作破坏性验收。

现场步骤
在另一台设备刷新网页并连接 → 本机登录状态下在“显示”配置虚拟屏 → 确认画面可操作 →
“隐私”开启并勾选显示器休眠 → 观察本机显示、在远端点击窗口并输入 → 本机唤醒确认仍需登录。
另测普通锁屏后网页连接保留，在网页输入 Mac 账户密码恢复，再点击并输入；密码不发聊天。
最后结束隐私会话、本机登录，确认屏幕与应用窗口恢复。完成以上证据前不标记目标完成。
